# Changelog: ship-it

## 1.1.0 (26 Nov 2026)

- Reviews the pull request before merging (new Step 10A). It fixes the defects the approved scope already decides, test-first, and gets the checks green within two fix rounds. It asks you about any choice the scope leaves open, such as a rounding rule, and holds the merge until you answer. One summary comment on the pull request records what was fixed and what was left.
- Later live checks are recorded as a new production verification comment in the same format, so the next session can read them.
