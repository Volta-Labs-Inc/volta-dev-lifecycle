# Changelog: scope

## 1.1.0 (19 Nov 2026)

- For Volta customer work, /scope now reads the approved 1.0 Solution Brief even if you don't have Volta's systems, from the file or link Volta sent you. If the brief isn't at 1.0 or you can't find it, /scope stops and asks for it instead of scoping without it. Internal, technical and your own projects still go ahead without one.

- First release in the Volta AI Development Lifecycle repository, taken from the version Volta was using on 19 Nov 2026.
